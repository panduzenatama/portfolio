e-Presensi

Complete Sistem manajemen kehadiran QR code untuk sekolah

Platform komprehensif untuk manajemen kehadiran siswa menggunakan QR code. Sistem ini dirancang untuk sekolah modern dengan fitur dashboard admin, multi-role access, pencatatan real-time, dan laporan PDF terstruktur. Admin dapat mengelola kelas, siswa, dan jadwal, sementara siswa dapat melihat riwayat kehadiran mereka.

Fitur Utama

QR Code Scanner
Scanning QR code untuk pencatatan kehadiran siswa secara real-time
Dashboard Admin
Ringkasan kehadiran kelas, persentase, dan trend kehadiran siswa
Manajemen Kelas & Siswa
CRUD lengkap untuk mengelola kelas, siswa, dan jadwal pembelajaran
Riwayat Kehadiran
Pencatatan detail kehadiran siswa per hari dengan filter dan pencarian
Laporan PDF
Generate laporan kehadiran bulanan/tahunan dalam format PDF profesional
Multi-Role Access
Admin dan student roles dengan kontrol akses berbasis keperluan
