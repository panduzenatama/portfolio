Tentang Proyek

Sistem manajemen absensi terintegrasi untuk sekolah dan lembaga pendidikan. Menggunakan teknologi QR code untuk pencatatan absensi real-time, dilengkapi dashboard admin untuk monitoring kehadiran siswa dan laporan PDF otomatis.

Dibangun dengan CodeIgniter 3 sebagai backend dan MySQL sebagai database. Fitur utama mencakup multi-role access (admin & siswa), manajemen kelas, event absensi, dan sistem permission untuk ijin/sakit.

Fitur Utama

  • → QR code scanning — absensi masuk/keluar real-time
  • → Dashboard admin — monitoring kehadiran per siswa/kelas
  • → Manajemen siswa & kelas — CRUD lengkap
  • → Event absensi — buat dan atur waktu event
  • → Sistem permission — ijin/sakit dengan dokumen upload
  • → Export PDF — laporan attendance per siswa/kelas

Tech Stack

CodeIgniter 3 PHP 8.3 MySQL Bootstrap 4 phpqrcode mPDF

Highlight Teknis

  • • Enkripsi URL parameter untuk keamanan data siswa
  • • Kompilasi ekstensi PHP GD untuk QR generation native
  • • Docker setup dengan PHP-FPM + MySQL untuk development
  • • Bcrypt password hashing untuk autentikasi secure
  • • Multi-role controller dengan authorization checks
