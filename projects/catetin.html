Catetin

In Progress Platform SaaS POS & manajemen warung modern

Platform all-in-one untuk mengelola warung/toko modern dengan fitur POS (Point of Sale), inventory management, customer management, penjualan, dan analytics. Dibangun dengan Next.js 16 dan Supabase untuk skalabilitas tinggi. Aplikasi mobile-first dengan dark theme profesional dan UX intuitif untuk pemilik warung.

Next.js 16
Supabase (PostgreSQL)
TypeScript
Tailwind CSS
React Hooks
Real-time Sync

Fitur Utama

POS System
Sistem kasir modern dengan multiple payment methods dan receipt printing
Inventory Management
Tracking stok real-time, automated reorder alerts, dan stock history
Customer Management
Database pelanggan, loyalty program, dan transaction history
Analytics & Reporting
Dashboard insights, sales analytics, profit margin, dan performance metrics
Mobile-First Design
Responsive design yang optimal untuk tablet dan smartphone
Real-Time Sync
Synchronisasi data real-time across devices dengan Supabase
