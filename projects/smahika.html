SMAHIKA

Archived Sistem manajemen sekolah berbasis web

Platform manajemen sekolah terpadu dengan fitur akademik, administrasi, dan pelaporan. Sistem ini dirancang untuk SMA dengan fitur manajemen siswa, kelas, nilai, pembayaran, dan raport online. Dibangun dengan CodeIgniter 3 dan Bootstrap untuk interface responsif.

CodeIgniter 3
PHP
MySQL
Bootstrap
PDF Report

Fitur Utama

Manajemen Data Siswa
Database siswa lengkap dengan profil, kontak, dan riwayat akademik
Manajemen Akademik
Kelas, mata pelajaran, jadwal, dan penilaian siswa
Generate Raport
Raport otomatis dalam format PDF dengan template profesional
Manajemen Pembayaran
Tracking pembayaran SPP dan biaya lainnya per siswa
